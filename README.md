Welcome to my README...

This game is designed to represent AI in advertisement. It does this by recreating what I feel is happening to the industry. 
Prestablished topics and products are used by AI (In this case, the user) and copied in order to mass produce simple and low-effort copies to be marketed out to customers.
I wanted to create something where the user is representing AI, and having them essentially "create" ads really showed how dehumanized the industry is.
IR (Image Recognition) has been on rise for ad personalization and creation (Ford), which is what the user is tasked to complete in this game.
over the course of the semester we learned about the benefits and drawbacks of AI which is displayed here by the obvious innacuracies by the user, contrasted by the quickness in which images can be produced.
It brings up the question of if being able to make ads the quickly is worth it.


INSTRUCTIONS:
When the site opens, press start game. trace the image to the best of your ability, and if you are accurate enough, you can continue.
